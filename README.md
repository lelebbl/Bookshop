# Mumei

## 📌 Описание проекта
Mumei - это полнофункциональный интернет-магазин

## ⚙️ Технологический стек
### **Backend**
- **Django**: Основной фреймворк.
- **PostregreSQL**: база данных для сохранения данных приложения.

### **Frontend**
- **HTML/CSS**: Базовая вёрстка и стилизация.
- **JavaScript**: Запросы к бэкенду.
